# v0.1 decisions

- Revit 2025, .NET 8, x64.
- User-started batch command only; no IUpdater.
- Plan and preview first; one transaction for approved Apply records.
- Duplicate wall types for targeted walls; never edit the source type.
- Symmetric Finish1/Finish2 only. Unequal existing finish widths with an unspecified rule thickness are skipped.
- Conflicting finish signatures, missing materials, and missing thickness are reported and skipped.
- Existing materials only; resolve by FinishCode then exact name.
- No purge, no material creation, no 3D preview.
- User-level Windows installer writes the manifest and payload under the Revit 2025 Addins folder.
